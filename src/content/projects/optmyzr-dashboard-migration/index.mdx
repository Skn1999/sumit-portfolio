## 01 // CONTEXT

Optmyzr relies on high-traffic, data-dense analytics applications to help digital marketers manage multi-platform advertising campaigns. As data volume scaled, legacy Backbone.js and jQuery view layers triggered cascading browser re-renders, driving time-to-interactive benchmarks to 8–10 seconds under enterprise workloads.

As Frontend Systems Engineer, I refactored the core account dashboard and comparison tool views. I engineered the config-driven layout compiler, built state isolation boundaries, and designed an LLM-assisted migration pipeline to refactor legacy templates into design-token-compliant React components.

---

## 02 // PROBLEM

Legacy view layers relied on un-scoped global state triggers. A single data property update triggered cascading re-renders across all mounted widgets, blocking the main looper thread and causing heavy UI latency. Adding support for new ad platforms required intrusive core state modifications and repetitive layout boilerplate.

## 03 // APPROACH

### Scoped Redux Data Slices
Segmented all data pipelines into isolated Redux Toolkit slices, eliminating cross-component render cascades. Each widget component subscribes strictly to the exact data properties it requires.

### Viewport-Driven Hydration
Rebuilt data delivery as a progressive pipeline where critical UI shells mount immediately. Heavy data visualization charts and deep data tables load asynchronously only when scrolled into the viewport.

### Metadata-Driven Runtime Rendering System
Built a dynamic rendering engine that interprets centralized JSON metadata checklists to assemble layouts at runtime. This eliminated layout boilerplate code and empowered zero-deployment modifications.

### Automated LLM Migration Pipeline
Engineered a human-in-the-loop AI refactoring pipeline using specialized context prompts. This programmatically converted thousands of legacy visual templates into design-token-compliant React wrappers.

## 04 // IMPACT

- **< 1s Time-to-Interactive:** Compressed enterprise dashboard load times from 8–10s down to under 1 second.
- **Zero Core State Overhead:** Enabled zero core state changes when onboarding new advertising platforms.
- **3× Component Reuse:** Standardized widget architecture across all account layouts and reporting tools.

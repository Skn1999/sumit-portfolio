## 3. Step-by-Step Instructions to Render in Google Flow (`labs.google/flow`)

1. **Open Google Flow**: Navigate to [labs.google/flow](https://labs.google/flow) and sign in.
2. **Create New Project**: Click **New Project** and set aspect ratio to **16:9** (Landscape, 1080p or 4K).
3. **Upload Reference Assets**:
   - In Google Flow's asset drawer, upload the corresponding screenshot from `src/content/projects/actai/` for each scene (e.g., `how-screen-a-today-light.png` for Scene 03, `how-screen-b-delegation-light.png` for Scene 04, etc.).
4. **Generate Clips (Image-to-Video Mode)**:
   - Select the uploaded reference image as the primary visual anchor.
   - Set Model to **Veo 2** / **Veo High Quality**.
   - Paste the corresponding scene prompt from the deck above into the prompt box.
   - Set motion intensity to **Subtle / Smooth (3/10)** to preserve the crisp text fidelity and avoid AI hallucinations.
5. **Timeline Assembly**:
   - Sequence the 9 generated clips along the timeline.
   - Apply a clean **Cross Dissolve (0.4s)** between UI transitions.
6. **Audio & Voiceover**:
   - Record or generate the voiceover using Google Flow's built-in speech tool or an elevenlabs / studio voiceover following the VO script.
   - Add a subtle ambient electronic soundtrack (low pass synth, warm Rhodes chord pads, gentle clock tick/haptic tap sound effects on button clicks).
7. **Export & Embed**:
   - Export as `actai-promo-video.mp4` (1080p, H.264/AAC).
   - Place into `src/content/projects/actai/` to embed directly into `index.mdx`.
